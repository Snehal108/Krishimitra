
🌾 Krishimitra - AI Driven Agriculture Assistant
📌 Purpose
Farmers in India face challenges such as uncertain weather, fluctuating market prices, lack of awareness of government schemes, and limited access to data-driven recommendations.
Krishimitra is built to empower farmers by providing real-time weather updates, market price insights, crop recommendations, and voice-based assistance — all in a simple, mobile-friendly web app.

📂 What’s in this Project?
🌦 Weather Forecasting – Fetches local weather conditions to help farmers plan agricultural activities.
📉 Market Price Insights – Provides live mandi prices for better selling decisions.
🤖 Recommendation Engine – Suggests crops, practices, and actions based on datasets.
🏛 Government Schemes – Highlights relevant policies and subsidies available to farmers.
🎙 Voice Input & Output – Farmers can ask questions in natural language and receive spoken responses.
📊 Datasets Integration – Curated datasets (soil, crops, pricing, weather) to enable AI-driven decisions.
⚡ Challenges & Solutions
Challenge 1: Access to diverse, unstructured agricultural data
Solution: Integrated multiple APIs (Weather, Market Prices, Govt. Schemes) into a single platform.

Challenge 2: Farmers’ digital literacy and language barrier
Solution: Added voice input/output for ease of use, allowing farmers to interact without typing.

Challenge 3: Real-time accuracy & reliability of information
Solution: Used API-based live data fetching and fallback datasets to ensure consistent results.

🔮 Future Scope
📱 Develop a dedicated mobile app for offline-first usage in rural areas.
🌐 Multilingual support for regional languages.
🤝 Collaboration with agri startups for supply chain integration.
🧠 AI-driven crop disease prediction using image recognition.
☁️ Deploy on scalable cloud infrastructure for nationwide adoption.
🆚 Why Different from Others?
Unlike typical portals, Krishimitra integrates multiple essential services into one (weather, mandi prices, schemes, recommendations).
Designed with a farmer-first approach: simple UI + voice support.
Focuses on real-time actionable insights rather than static information.
Built lightweight and modular, so new datasets or APIs can be added easily.
🛠 Tech Stack
Frontend: React.js, Tailwind CSS
Backend: Node.js, Express.js
Database: MongoDB (for datasets and user preferences)
APIs: Weather API, Market Price API, Govt. Schemes API
Voice Tech: Web Speech API for input/output
Other Tools: Git, GitHub
